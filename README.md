# cdc-research-project

## Notebooks and data

- `tornado_data_analysis.ipynb`: NOAA extraction and data-quality analysis, with inputs and provenance in `data/tornado_extract/`.
- `tornado_vulnerability_analysis.ipynb`: county vulnerability, hospital access, and regression analysis, with required inputs and documentation in `data/vulnerability_analysis/`.

Open notebooks using a Python environment with their required dependencies. For the vulnerability notebook: NumPy, pandas, GeoPandas, Matplotlib, seaborn, SciPy, statsmodels, and ipykernel. Its final regression section can run independently using the included combined county dataset.

Generated figures, local backup files, and intermediate exploration exports are excluded from version control.
